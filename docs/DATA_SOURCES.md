# 실제 데이터 출처 관리

아직 승인/등록된 실제 데이터 출처가 없다. 담당자는 다음 열을 유지한다.

| 영역 | 공식 URL | 사용 허가/API 약관 | robots 확인일 | 수집 주기/제한 | 수집일 | 검수자 | 공개 상태 |
| ---- | -------- | ------------------ | ------------- | -------------- | ------ | ------ | --------- |

행사 B, 할인 C 담당. 공식 API 우선, 허가된 공개 소스만 수집. 로그인/CAPTCHA 우회 금지. 원본/해시/출처/시각 보존, 정규화, 중복 제거, 변경 감지, 검수 후 공개. AI 추론값은 원문 확인 전 미확인. 가격/라인업/대기시간/할인 생성 금지. 오류/재시도/속도 제한/수집 금지 상태도 기록한다. 테스트 fixture는 tests/fixtures 안에 격리.
