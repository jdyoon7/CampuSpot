# 보안 기준

.env.local과 서버 키는 Git 금지. VITE_ 변수는 전부 사용자에게 공개된다고 간주. 브라우저는 publishable key만 사용하며 반드시 RLS로 보호한다. service role은 서버에서도 최소 사용 및 권한 검증 필수.

가입/학교 인증/역할 승격 분리. 이메일 도메인 입력만으로 학교 인증 완료 처리 금지. 관리자/매장 권한 서버 확인. 개인정보 공개 범위 최소화. 익명 게시글 작성자 서버 보관. 채팅은 멤버십 기반 SELECT/Realtime 정책 검증.

모임 제한 조건은 쿼리 이후 브라우저 필터가 아닌 DB/RLS/서버에서 검사. 포인트/쿠폰/결제는 동시성/재전송 공격 검증. 업로드는 크기/실제 형식/접근 정책 검증. 로그에 토큰/인증자료/개인정보를 남기지 않는다.

키 노출 시 키 폐기/재발급 후 이력 정리 필요. 단순 파일 삭제로 유출이 해소되었다고 보고하지 않는다. npm audit의 실패를 임의로 무시하거나 audit fix --force로 해결하지 않는다.
