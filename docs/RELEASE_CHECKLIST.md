# 출시 전 검증 (현재 모두 미완료)

- [ ] 가입/복구/탈퇴/학교 인증 및 역할별 권한 검증
- [ ] 전 테이블/Storage/Realtime RLS, 타인/anon 접근 공격 검증
- [ ] 정원/포인트/쿠폰 동시성, 결제 서버 검증 및 웹훅 멱등성
- [ ] 모든 주요 기능 실제 데이터 연동, 출처/업데이트/만료 표시
- [ ] 모바일/접근성/실패/로딩/빈 화면/E2E 및 DB 통합 테스트
- [ ] PWA manifest/icon/service worker 업데이트 및 로그아웃 개인정보 캐시 제거
- [ ] 개발/staging/production 분리, secrets, 백업/복구 연습
- [ ] Sentry/PostHog/FCM 동의 범위 및 개인정보 제거
- [ ] 이용약관/개인정보/위치/광고/환불/고객 문의 및 국내 운영 요건 전문 검토
- [ ] 비용/장애 대응/롤백, 팀 승인 후 실제 배포

이 문서는 법적 적합성 확인서가 아니다. 운영 요건은 출시 시 최신 공식 자료와 전문가 검토로 확정한다.
