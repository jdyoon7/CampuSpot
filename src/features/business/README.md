# 매장·지점

**할인·혜택 → 매장·지점**에서 로그인 없이 지점명, 주소, 공식 정보, 현재 공개 중인 연결 혜택을 확인합니다. 공개 혜택 목록과 캘린더의 **매장 정보** 링크도 같은 지점 상세로 이동합니다.

매장 목록, 지점 상세, 관심 매장의 **카카오맵에서 보기**는 등록된 주소 또는 건물명으로 카카오맵 검색을 엽니다. 고려대 식당처럼 도로명 주소를 공유하는 건물은 이름으로 찾을 수 있고 식당 층은 CampuSpot의 주소에서 확인할 수 있습니다. [카카오맵 검색 링크 가이드](https://apis.map.kakao.com/web/guide/)

관리자 또는 최고 관리자는 목록에서 **매장·지점 등록**을 엽니다. 매장명, 지점명, 주소, 공식 출처를 확인해 등록한 뒤 지점 상세에서 **공개 혜택 연결하기**를 열 수 있습니다. 같은 이름의 다른 지점은 별도 UUID를 받습니다. 이미 다른 지점에 연결한 혜택을 옮기려면 기존 지점에서 연결을 해제해야 합니다.

`20261126074624_discounts_business_directory.sql`은 지점 정보와 혜택 연결을 추가합니다. 브라우저는 공개 필드만 읽을 수 있고, 등록은 RLS에서 관리자 권한과 등록 주체를 확인합니다. 연결 변경은 승인된 공개 혜택만 처리하는 관리자 RPC를 통합니다. 기존 혜택의 매장명과 내용은 지점 연결 전후에도 보존되며, 연결을 해제해도 혜택 자체는 계속 공개됩니다.

공유 개발 프로젝트에서 고려대학교 한투스퀘어, 애기능생활관, 안암학사 식당을 등록하고 기존 혜택 3건을 각각 연결했습니다. 주소는 서울캠퍼스 기준이며 상세 위치는 건물과 층을 표시합니다. [캠퍼스 주소](https://scholarship.korea.ac.kr/temp_g/info/map.do) · [학생회관](https://www.korea.ac.kr/diet/ko/13/view.do) · [애기능생활관](https://www.korea.ac.kr/diet/ko/9/view.do) · [안암학사](https://www.korea.ac.kr/diet/ko/10/view.do)

지점 상세에서 **이 지점 팔로우**를 누르면 **매장·지점 → 관심 매장**에 표시됩니다. 팔로우 목록은 로그인한 본인만 볼 수 있습니다. 같은 이름의 지점은 각자 팔로우할 수 있습니다. 지점 상세에서 해제하면 해당 지점의 앱 내 혜택 알림도 사라집니다.

관리자는 지점 상세의 **매장 검색 분류 수정**에서 인근 학교, 지역(시·구)과 업종을 입력할 수 있습니다. 학교는 등록된 학교 중에서 선택하고 지역명은 기존 표기를 따릅니다. 해당 지점에 연결된 공개 혜택에서 필터 선택지가 생깁니다.

회원은 지점 상세에서 운영자 권한을 신청합니다. **혜택 제보 검수 → 매장 운영자 검수**에서 관리자가 신청을 승인·반려하거나 기존 운영 권한을 해제할 수 있습니다. 한 지점당 운영자 한 계정을 승인하며 운영 권한을 해제하면 해당 지점의 쿠폰 발급과 사용을 중지합니다.

승인된 운영자는 지점의 소개, 영업시간과 메뉴·가격 링크를 편집하고 검수받을 할인과 쿠폰 캠페인을 등록합니다. 쿠폰 발급과 사용은 서버가 지점 권한, 재고, 기간, 대상 학교 인증, 중복 사용을 확인합니다. 운영자만 발급·사용 건수 확인과 쿠폰 중지·재개를 할 수 있습니다.

지도 링크 추가 후 `npm run check`, `npm run test:e2e`와 공유 개발 DB를 사용한 모바일 조회를 통과했습니다. 고려대 식당 3곳의 검색어와 새 창 열기를 확인했습니다.

`npm run check`와 `npm run test:e2e`를 통과했습니다. 공유 개발 DB에서 롤백 방식 SQL 검사 15개를 실행했고, 모바일에서 비회원 조회와 관리자 등록·연결·해제를 검증했습니다. 로컬 Docker DB 전체 테스트는 실행하지 않았습니다.

### 매장 대표 사진

승인된 운영자는 **내 매장 관리 → 매장 사진**에서 대표 사진 한 장을 공개·교체·내릴 수 있습니다. 저장 함수가 파일을 다시 디코딩하고 현재 운영 권한을 확인합니다. 비공개 `business-photos` 버킷에서 지금 지점에 연결된 사진만 공개 조회되며, 이미 발급된 서명 URL은 최대 2분 유효합니다. `20261127070500_discounts_nearby_and_photos.sql` 적용 후 `discount-business-photo` Edge Function을 연결합니다. 관리자는 **매장 검색 분류 수정**에서 거리순 검색용 위도와 경도를 입력합니다.
