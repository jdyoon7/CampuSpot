# 관심 매장 혜택 알림

로그인한 회원은 **할인·혜택 → 혜택 알림**에서 팔로우한 지점의 알림을 확인하고 하나씩 읽음 처리할 수 있습니다. 알림은 화면을 열거나 새로고침할 때 최신 결과를 읽습니다.

- **새 혜택**은 팔로우 이후 처음 공개됐거나 해당 지점에 연결된 혜택입니다. 최대 30일 동안 조회합니다.
- **혜택 시작**은 팔로우·공개 후 시작일이 찾아온 혜택입니다. 시작일을 포함해 7일 동안 조회합니다.
- **마감 임박**은 이용 기간에 들어온 혜택 중 한국 날짜 기준 오늘부터 6일 이내 종료되는 혜택입니다.

공개가 중단됐거나 종료된 혜택의 알림은 숨깁니다. `20261126075715_discounts_business_follows.sql`에서 공개 혜택과 본인 팔로우를 기준으로 알림을 조회하고, 실제 알림에 대한 읽음 기록만 저장합니다. 팔로우를 해제하면 해당 지점의 읽음 기록도 정리됩니다. 모바일 푸시, 이메일과 공통 알림은 후속 작업입니다.
